# Custom Local Web App Guide

V1 supports URL registration only.

Use this for a local web app that is already running:

- `http://localhost:3000`
- `http://127.0.0.1:3000`
- `http://192.168.x.x:3000`

If an iPad or another PC needs to open the app, do not use `localhost`; use the host PC's LAN address or hostname.

Static app upload and app runner commands are not part of V1.
