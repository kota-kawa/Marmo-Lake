# AI Settings

V1 supports:

- OpenAI-compatible chat APIs
- Ollama

OpenAI-compatible settings:

- endpoint, for example `https://api.openai.com/v1`
- model, for example `gpt-4o-mini`
- API key

Ollama settings:

- endpoint, for example `http://127.0.0.1:11434`
- model, for example `llama3.1`

API keys are encrypted locally and are not included in normal backup export.

AI Actions are limited to registered actions. V1 actions can open a screen, search basic workspace content, draft a note, create a note after confirmation, and update a checklist item after confirmation.
