# First Workspace Guide

V1 starts locked until initial setup is complete.

Recommended first workspace:

1. Choose the closest scene: shop, classroom, office, community, or empty.
2. Set a real admin password.
3. Open the staff home.
4. Add one work app URL from Admin.
5. Add one checklist and one important announcement.
6. Confirm the staff home after refreshing the browser.

The default template adds a first announcement, memo, and checklist so the home screen is never blank.
